# FoxHunt et Beacon

Cette page de compatibilité conserve les liens créés pour les versions du firmware où `FOX HUNT / BEACON` était une action combinée.

Depuis `v6.0.0`, ce sont deux applications indépendantes et deux actions programmables indépendantes :

* [FoxHunt](./Fox-Hunt) est un outil de radiogoniométrie de réception uniquement.
* [Beacon](./Beacon) est un émetteur Morse automatique.

Le nom combiné est conservé uniquement lors de la description de l'implémentation historique de `v5.8.0` et `v5.9.0`. Les instructions, commandes, disponibilités et informations de sécurité actuelles sont conservées sur les deux pages distinctes ci-dessus.
