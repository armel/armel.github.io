# Накладные приложения

На этой странице описаны одиннадцать приложений, доступных в настоящее время для издания `Labs`: что они делают и как ими управлять. Информацию об установке, совместимости и разработчике см. в [Оверлейные приложения](./Overlay-apps).

> [!NOTE]
> Навигационные клавиши зависят от радио и настройки `SetNav`: `UP` / `DOWN` на UV-K5 или `LEFT` / `RIGHT` на UV-K1. В таблицах ниже `UP/LEFT` и `DOWN/RIGHT` относятся к этим эквивалентным ключам.

## Запуск приложения

1. Установите совместимый файл `.app` с [UV Studio](./UV-Studio#apps-labs).
1. Из обычного радиоэкрана нажмите `F`, затем `7 VOX`.
1. Выберите установленное приложение с `UP/LEFT` или `DOWN/RIGHT`.
1. Нажмите `M`, чтобы запустить его.

В большинстве приложений `EXIT` закрывает приложение и возвращается к пусковой установке или обычному радиоэкрану. Некоторые радиоприложения также могут быть назначены непосредственно программируемому ключу через обычное устройство выбора действия.

## Резюме заявления

| Применение | Цель |
| --- | --- |
| `Broadcast FM` | Полнофункциональный широковещательный FM-приемник с VFO, памятью и сканированием станции |
| `FoxHunt` | Сигнальная сила и помощь в поиске направления с историей, ослаблением и аудионаведением |
| `Beacon` | Повторение Морзе-маяка в стиле ARDF с использованием выбранной передачи VFO |
| `Beam` | Transfer - конфигурация одного канала между совместимыми радиостанциями по воздуху |
| `Breakout` | Брик-брейк игра |
| `Tetris` | Falling-block игра с забиванием, уровнями и сохраненным лучшим счетом |
| `Cube3D` | Анимированный 3D-видетель формы |
| `Plasma` | Анимированные шаблоны в стиле демонстрантов |
| `Snake` | Классическая игра на основе сетки змеи с сохраненным лучшим счетом |
| `Rapid Roll` | Платформенная игра, в которой шар должен спускаться, избегая препятствий |
| `Space Impact` | Космический шутер с боковой прокруткой, автоматическим огнём, ракетами и боссами |

## Broadcast FM

`Broadcast FM` является полным приемником BK1080. Он обеспечивает частоту и режимы памяти, четыре полосы вещания, ручной поиск, автоматическое обнаружение станции и 48 FM-памятей, совместно используемых с резидентным FM-радио.

Пока это приложение работает, обычные функции приема BK4819 и двойных часов приостановлены. Изменения в памяти FM безопасно вносятся при выходе приложения.

| Ключ | Меры |
| --- | --- |
| `0`-`9` | Введите частоту в режиме VFO или двузначный номер памяти в режиме MR/save |
| `UP/LEFT` или `DOWN/RIGHT` | Настройте один шаг в режиме VFO; выберите предыдущую / следующую сохраненную станцию в режиме MR; выберите слот сохранения; измените направление поиска при сканировании |
| `*` | Начните поиск вручную; остановите активное сканирование |
| `F`, затем `*` или удерживайте `*` | Начните автоматическое сканирование и восстановите список памяти FM |
| `M` в режиме VFO | Откройте `SAVE?`; нажмите `M` снова, чтобы сохранить в выбранном слоте |
| `M` в режиме MR | Откройте `DEL?`; нажмите `M` снова, чтобы удалить выбранную память |
| `F`, затем `1` или удерживайте `1` | Выберите следующую полосу вещания |
| `F`, затем `3` или удерживайте `3` | Переключение между режимами VFO и MR |
| `F`, затем `0` или удерживайте `0` | Выйти из приложения |
| `EXIT` | Стирайте последнюю введенную цифру, отменяйте подсказку сохранения / удаления или выход |

> [!WARNING]
> Автоматическое сканирование очищает и восстанавливает список памяти FM, прежде чем хранить найденные станции.

## FoxHunt

`FoxHunt` помогает найти передатчик, используя выбранный прием VFO. Он показывает скорректированную силу сигнала в dBm, S-метр в стиле IARU, пиковые и минимальные уровни, информацию о тренде и либо бар-граф, либо историю сигнала. Выбираемое затухание расширяет полезный диапазон близко к сильному передатчику.

| Ключ | Меры |
| --- | --- |
| `1` | Переключитесь между бар-графом и историей сигнала |
| `2` | Выберите следующий аудиорежим: выключен, звуковой сигнал силы или непрерывный звук станции |
| `3` | Увеличение затухания |
| `F`, затем `2` | Выберите предыдущий режим аудио |
| `F`, затем `3` | Уменьшение ослабления |
| `UP/LEFT` или `DOWN/RIGHT` | Увеличение/сокращение затухания непосредственно |
| `M` | Сброс пиковых, минимальных и трендовых эталонных значений |
| Держите `F` | Заблокировать или разблокировать клавиатуру приложения |
| `EXIT` | Выход, пока клавиатура разблокирована |

График, аудиорежим и настройка затухания сохраняются для следующего запуска. Два навигационных ключа остаются доступными, пока клавиатура приложения заблокирована.

## Beacon

`Beacon` неоднократно передает идентификатор Морзе в стиле ARDF на выбранный передатчик VFO. Он чередуется между настраиваемым окном передачи и периодом простоя. Доступными идентификаторами являются `MOE`, `MOI`, `MOS`, `MOH`, `MO5`, `MO` и `CALL`; `CALL` отправляет сконфигурированный позывной, за которым следует `MOE`.

| Ключ | Меры |
| --- | --- |
| `1` | Увеличение продолжительности передачи в 5-секундных шагах (`5`-`60` секунд) |
| `2` | Увеличение продолжительности простоя в 5-секундных шагах (`5`-`240` секунд) |
| `3` | Выберите следующий идентификатор |
| `4` | Переключить режим `TONE` / `CARR` |
| `F`, затем `1` / `2` / `3` / `4` | Измените соответствующую настройку в обратном направлении |
| `M` во время передачи | Остановите текущее окно передачи и начните период простоя |
| `M` в режиме ожидания | Перезагрузите полный обратный отсчет |
| Держите `F` | Заблокировать или разблокировать все элементы управления приложениями |
| `EXIT` | Остановитесь безопасно и выходите, пока элементы управления разблокированы |

Первая передача начинается немедленно. Продолжительность, время простоя, идентификатор и режим клавиши сохраняются для следующего запуска. Если резидентная прошивка отказывается от передачи, приложение отображает `TX OFF` и не передает.

> [!WARNING]
> Beacon передается автоматически. Проверьте выбранный VFO, частоту, мощность, антенну, позывной, рабочий цикл и местные правила перед запуском.

## Beam

`Beam` передает выбранную конфигурацию VFO или канала памяти между совместимыми радиостанциями. Передающее радио передает данные канала по воздуху; принимающее радио хранит действительный пакет в первой свободной памяти.

| Ключ | Меры |
| --- | --- |
| `UP/LEFT` или `DOWN/RIGHT` | Переключайтесь между режимами передачи (`BEAM TX`) и приема (`BEAM RX`); также прекращайте активную операцию приема. |
| `M` в режиме TX | Отправьте выбранную конфигурацию канала |
| `M` в режиме RX | Начните ждать пакет Beam |
| `EXIT` | Прекратить прием или выйти из приложения |

Дисплей сообщает `SENT`, `RECEIVED`, `MEM FULL` или `ERROR` соответственно. За один запуск выполняется только один полученный канал; выход и повторное открытие Beam перед получением другого.

## Breakout

`Breakout` - это компактная игра с 18 кирпичами, пятью стартовыми мячами, счетом и отслеживанием уровня. Очистка стены начинается на следующем уровне и присуждает дополнительный мяч.

| Ключ | Меры |
| --- | --- |
| `4` или `UP/LEFT` | Двигайте весло влево |
| `0` или `DOWN/RIGHT` | Двигайте весло вправо |
| `M` | Приостановка или возобновление; после `GAME OVER` запустите подготовленную новую игру |
| `EXIT` | Выйти из приложения |

Прогресс игры не сохраняется после выхода из приложения.

## Tetris

`Tetris` использует 16×16 видимый колодец, перетасованную сумку из семи частей, призрачную часть, предварительный просмотр следующей части, оценку, линии и уровни. Лучший результат сохраняется между запусками.

| Ключ | Меры |
| --- | --- |
| `4` или `UP/LEFT` | Двигаться влево |
| `6` или `DOWN/RIGHT` | Вперед. |
| `M` или `2` | Поверните кусочек |
| `8` | Мягкая капля |
| `*` или `0` | Жесткое падение |
| `F` | Пауза или продолжение |
| `M`, `*` или `0` после окончания игры | Начните новую игру |
| `EXIT` | Выйти из приложения |

Движение и мягкая капля повторяются, пока хранятся ключи.

## Cube3D

`Cube3D` отображает вращающиеся твердые или каркасные формы. Доступны восемь форм: куб, октаэдр, тетраэдр, алмаз, икосаэдр, кубоктаэдр, шестиугольная призма и пятиугольный камень.

| Ключ | Меры |
| --- | --- |
| `UP/LEFT` или `DOWN/RIGHT` | Увеличение/снижение скорости вращения (`1`-`16`) |
| `1`-`8` | Выберите форму напрямую |
| `*` | Выберите следующую форму |
| `F` | Переключить каркасный/сплошной режим |
| `M` | Пауза или продолжение |
| `EXIT` | Выйти из приложения |

## Plasma

`Plasma` отображает анимированные полноэкранные шаблоны в стиле демосцены с полосами или сшипованным рендерингом.

| Ключ | Меры |
| --- | --- |
| `UP/LEFT` или `DOWN/RIGHT` | Увеличение / снижение скорости анимации (`1`-`8`) |
| `1`-`5` | Выберите шаблон и отключите автоматическую езду на велосипеде |
| `*` | Переключить полосы/точечный режим |
| `F` | Включить или отключить автоматический цикл |
| `M` | Пауза или продолжение |
| `EXIT` | Выйти из приложения |

## Snake

`Snake` - это классическая игра в стиле Nokia, в которую играют на сетке `31 × 13`. Ешьте пищу, чтобы вырастить змею и набрать `10` баллов. Удар по границе или собственному телу змеи завершает игру. Лучший результат сохраняется между запусками.

| Ключ | Меры |
| --- | --- |
| `2` или `3` | Вставай. |
| `4` или `5` | Двигаться влево |
| `6` или `0` | Вперед. |
| `8` или `9` | Спуститься |
| `F` | Пауза или продолжение |
| `M`, `*` или `0` после окончания игры | Начните новую игру |
| `EXIT` | Выйти из приложения |

Удержание ключа направления повторяет его. Заявка отказывает в немедленном обращении в собственное тело змеи. Если заставка активируется во время игры, Snake приостанавливается и возобновляется после пробуждения.

## Rapid Roll

`Rapid Roll` — платформенная игра, в которой платформы поднимаются к потолку с шипами. Перемещайте шар в стороны и спускайтесь с одной безопасной платформы на другую. Платформы с шипами, потолок и нижний край экрана отнимают одну жизнь; начиная с уровня 3 появляются разрушающиеся платформы. Сердца дают `50` очков и восстанавливают одну жизнь, но всего их может быть не более пяти.

| Кнопка | Действие |
| --- | --- |
| `4` или `UP/LEFT` | Катить влево |
| `6` или `DOWN/RIGHT` | Катить вправо |
| `F` | Пауза или продолжение |
| `M` после окончания игры | Начать новую игру |
| `EXIT` | Выйти из приложения |

Игра начинается с трёх жизней и ускоряется с повышением уровня. На высоких уровнях безопасные платформы становятся уже. После выхода из приложения прогресс не сохраняется. Если во время игры включится заставка, Rapid Roll приостановится и продолжится после пробуждения радиостанции.

## Space Impact

`Space Impact` — космический шутер с боковой прокруткой. Корабль автоматически стреляет из основного оружия, поэтому управление используется для перемещения по вертикали. Волны противников следуют разным схемам движения и атаки; в конце каждого уровня появляется босс с видимой шкалой здоровья.

| Кнопка | Действие |
| --- | --- |
| `2` или `UP/LEFT` | Переместить корабль вверх |
| `8` или `DOWN/RIGHT` | Переместить корабль вниз |
| `5` или `M` | Выпустить пробивную ракету |
| `F` | Пауза или продолжение |
| `M` после окончания игры | Начать новую игру |
| `EXIT` | Выйти из приложения |

Игра начинается с трёх жизней и трёх ракет. Основное оружие стреляет автоматически. За каждые 16 уничтоженных противников выдаётся ещё одна ракета, максимум до девяти. Победа над боссом даёт дополнительную жизнь и ракету, если соответствующие пределы ещё не достигнуты. После выхода из приложения прогресс не сохраняется. Если во время игры включится заставка, Space Impact приостановится и продолжится после пробуждения радиостанции.
