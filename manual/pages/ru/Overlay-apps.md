# Overlay приложения

Накладные приложения - это небольшие программы `.app`, хранящиеся во внешнем Flash и загружаемые в выделенное рабочее пространство оперативной памяти `4 KiB` только при запуске. Они позволяют экспериментальному изданию `Labs` добавлять инструменты, радиорежимы, визуальные демонстрации и игры без постоянной установки каждого приложения во внутренний Flash прошивки.

> [!WARNING]
> Приложения Overlay являются экспериментальной функцией `v6.0.0`. В настоящее время только версия `Labs` содержит загрузчик приложения. Приложения привязаны к прошивке ABI, уровню API, адресу оперативной памяти и дополнительным возможностям резидента; обновление или переустановка приложения, если радио сообщает об ошибке совместимости.

## Как работает платформа

Радио обеспечивает слоты для внешних приложений `8`. Каждый слот содержит заголовок плюс код приложения максимум `4 KiB`. Перед запуском приложения загрузчик проверяет:

* Формат файла / заголовка приложения и совершенное состояние
* Требуемый ABI и минимальный уровень API
* Размер кода и адрес ссылки RAM
* требуемые резидентные возможности прошивки приложения
* CRC-32 кода после его загрузки в оперативную память

Внутренняя прошивка Flash никогда не переписывается при установке, запуске или удалении приложения. Плохое или несовместимое приложение отклоняется, а не выполняется.

Текущий каталог содержит одиннадцать приложений: радиоинструменты, такие как `Broadcast FM`, `FoxHunt`, `Beacon` и `Beam`, плюс `Breakout`, `Tetris`, `Cube3D`, `Plasma`, `Snake`, `Rapid Roll` и `Space Impact`. См. [Справочник приложений](./Overlay-applications) для документированных приложений и их элементов управления. Доступность зависит от двоичных файлов приложений, распределенных для выбранной версии прошивки, и от возможностей, собранных в запущенную прошивку Labs.

## Установка приложения с UV Studio

1. Запустите радио обычно с выпуском `Labs`.
1. Подключите его к настольному браузеру с поддерживаемым соединением данных USB.
1. Откройте [UV Studio](https://armel.github.io/uvstudio/) и выберите `Apps` (`Labs only`).
1. Выберите версию прошивки и совместимое приложение из официального каталога или выберите локальный файл `.app`.
1. Выберите целевой слот приложения.
1. Выберите `Install app` и дождитесь завершения записи и проверки.

UV Studio может обновить игровой стол, показать имя, версию, размер и статус каждого приложения и удалить приложение, не касаясь остальной части радио.

Слоты приложения пронумерованы от `1` до `8` в UV Studio и в радиопусковой установке `F + 7`.

## Запуск приложения

1. Из обычного радиоэкрана нажмите `F`, затем `7 VOX`.
1. Используйте `UP` / `DOWN` на UV-K5 или `LEFT` / `RIGHT` на UV-K1, чтобы выбрать один из восьми отображаемых слотов. Активный макет следует за `SetNav`.
1. Нажмите `M` для запуска выбранного приложения.
1. Используйте элементы управления, показанные этим приложением; в большинстве приложений `EXIT` возвращается на пусковую установку приложения или обычный радиоэкран.

Пустые слоты остаются видимыми в пусковой установке. Выбранный слот и положение прокрутки запоминаются до перезапуска радио. Запуск и совместимые приложения отображаются в UV Studio.

Некоторые приложения также могут рекламировать одно из обычных программируемых действий: `FM RADIO`, `FOX HUNT`, `BEACON` или `BEAM`. Когда приложение для сопоставления установлено и действует, это действие может запустить его непосредственно из назначенного ключа или бокового набора действий. Если более одного установленного приложения рекламирует одно и то же действие, используется слот с наименьшим количеством номеров.

## Сообщения о совместимости

| Радиограмма | Значение/действие |
| --- | --- |
| `UPDATE APP` | Формат приложения, ABI, размер или адрес ссылки старше или несовместимы; установите соответствующую сборку приложения |
| `UPDATE FIRMWARE` | приложение требует нового API приложения; обновление прошивки Labs |
| `REINSTALL APP` | Запись неполная или код CRC неправильный; снова установите файл `.app` |
| `NOT SUPPORTED` | Приложение нуждается в резидентной способности, которую эта сборка Labs не включает в себя. |
| `NO APP` | Выбранный слот пуст или не имеет действительного заголовка приложения |

После выхода приложения погрузчик восстанавливает выбранный VFO, получает / двухчасовую настройку, обработку подсветки и внешний кэш-память. Приложения, которые модифицируют поддерживаемые общие данные, такие как предустановки Broadcast FM или данные канала Beam, просят резидентную прошивку выполнить его после того, как код оверлея перестал работать.

## Создание приложений из источника

Разработчики могут создавать приложения, присутствующие в репозитории прошивки:

```sh
./compile-app.sh
./compile-app.sh All
./compile-app.sh fm foxhunt
```

Сгенерированные файлы `.app` размещаются в `build/Apps/`. Каждое приложение связано с настроенным адресом наложения прошивки и упаковано с его метаданными и CRC. Восстановление приложений при изменении ABI, API, требуемых возможностей или наложения адреса.
