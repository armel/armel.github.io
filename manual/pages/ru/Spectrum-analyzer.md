# Анализатор спектра

## Экран обзора спектра

Нажмите `F` + `5 NOAA`, чтобы включить анализатор **Spectrum**.
Нынешняя частота VFO или памяти будет ** центровой частотой** спектрального диапазона.

![Spectrum Analyzer 1](https://github.com/user-attachments/assets/a445dca8-f7e9-4053-bbc9-9d373b03ed2c)

![Spectrum Analyzer 2](https://github.com/user-attachments/assets/01504dbf-e67b-45d3-9c56-b8ebb6b06e05)

Анализатор спектра также может использоваться в режиме [**ScnRng**](./Scanning#scan-frequency-range-function).

> [!NOTE]
> Навигация использует `UP` / `DOWN` на UV-K5 или `LEFT` / `RIGHT` на UV-K1. Активный макет следует за `SetNav`.

> [!NOTE]
> `PTT` открывает детальный мониторинг последней полученной частоты
> С `ScnRng` черный список ограничен 15 частотами.

> [!IMPORTANT]
> ** Анализатор спектра не ведет себя одинаково на радиоаппаратных средствах.**
> Радиостанции **V1/V2** построены вокруг приемника **BK4819**.
> **V3 (K5v3)** использует **BK4829**. Это различные приемные чипы, с
> различные этапы усиления LNA/PGA, поведение AGC и масштабирование RSSI.
>
> В результате:
> **шумовой пол**, абсолютные показания **dBm / S-метр** и значения **`LNAs` / `LNA` / `PGA`** не являются непосредственно сопоставимыми ** между V1 / V2 и V3 — настройка уровня или усиления, которая выглядит «правильно» на V2, не имеет оснований для обозначения То же самое на V3;
> - анализатор спектра был существенно переработан для поддержки обеих платформ, поэтому не ожидайте, что V3 будет воспроизводить то, что вы наблюдали на более старом V1/V2;
> - высокий или нестабильный шумовой пол в значительной степени обусловлен передней частью приемника и локальной радиочастотной средой, а не ошибкой в анализаторе. Когда **AUTO** не может осесть на вашем местном этаже, переключитесь на **MANUAL** и установите триггер самостоятельно — это именно то, для чего предназначен режим MANUAL.

### Режимы триггеров: AUTO vs MANUAL

`M` короткого нажатия для переключения между **AUTO** и **MANUAL** триггерными режимами. Верхний левый индикатор показывает активный режим:

- **`A:NORM`**/**`A:WEAK`**/**`A:STRG`** — режим AUTO. Уровень триггера отсчета отслеживает измеренный уровень шума, используя профиль чувствительности:
  - `WEAK` - +12 дБ над уровнем шума (наименее чувствительные, меньше ложных отверстий)
  - `NORM` — +8 дБ (по умолчанию)
  - `STRG` — +5 дБ (наиболее чувствительный)
  
  Стрелка направления прилагается к этикетке, чтобы показать текущее направление разметки:
  - `>` — sweep going left
  - `<` — sweep going right — влево
  
  Пример: `A:NORM>` означает AUTO / Нормальная чувствительность, разметка справа.

- **`M <rssi>/<trig>`** — ручной режим. Вы сами устанавливаете уровень триггера сжатия с помощью `*` / `F` и вертикальной шкалы (`dbMax`) с `3` / `9`. Триггерные изменения в предсказуемых шагах `1 dB`.

Удерживайте `M`, чтобы **сбросить анализатор спектра к настройкам по умолчанию**.

### Экономия настроек на выходе

При выходе с экрана **Обзор спектра** с помощью `EXIT` анализатор сохраняет постоянные настройки во Flash-памяти. При следующем открытии эти значения восстанавливаются:

- Стадия частоты между барами (`1` / `7`)
- Количество полос/каналов (`4`)
- пропускная способность приемника, используемая при мониторинге сигнала (`6`)
- **AUTO** или **MANUAL** (`M` short)
- Профиль чувствительности AUTO, **WEAK**/**NORM**/**STRG** (`3`/`9` в режиме AUTO)
- squelch trigger level (`*`/`F`) — восстанавливается в режиме **MANUAL**; в **AUTO** триггер вычисляется с шумового пола при каждом открытии анализатора

Эта стойкость была расширена после `v5.4.0`: старые сборки сохраняли только шаг сканирования, счетчик баров и пропускную способность приемника. В текущих сборках запуск анализатора спектра из режима `ScnRng` больше не перезаписывает сохраненный шаг сканирования или предпочтение бар-счета; активный диапазон сканирования по-прежнему определяет размах развертки.

Вертикальная шкала (`dbMax`, `3` / `9` в MANUAL) не сохраняется: она сбрасывается в окно дисплея по умолчанию каждый раз, когда анализатор открывается. Текущая частота развертки / окно, шаг прокрутки `UP` / `DOWN`, тип модуляции, переключение подсветки, временный черный список и корректировки регистра мониторинга деталей (`LNAs`, `LNA`, `PGA`) также не сохраняются этим действием `EXIT`. Если вы находитесь на экране **Detail Monitor**, `EXIT` сначала возвращается на экран сканирования; нажмите `EXIT` снова оттуда, чтобы сохранить и покинуть анализатор.

Текущие сборки также улучшают округление частоты `8.33 kHz` в рабочих процессах диапазона / спектра, поэтому отображаемые и настроенные частоты остаются более предсказуемыми на этапах в авиационном стиле.

### Функция кнопки

| Ключ | Функция |
| --- | --- |
| `1` / `7` | Стадия увеличения / уменьшения частоты между барами |
| `2` / `8` | Увеличение/уменьшение частоты, используемой при прокрутке с помощью `UP`/`DOWN` |
| `3` / `9` | В MANUAL: регулировка `dbMax` (вертикальная шкала) · В AUTO: профиль чувствительности цикла (`WEAK` ≤ `NORM` ≤ `STRG`) |
| `4` | Переключите количество полос (каналов) в графе |
| `5` | Частотный вход для более низкой частоты развертки (значение в **МГц**, `*` = десятичная точка) |
| `6` | Пропускная способность приемника |
| `0` | Переключить тип модуляции (FM / AM / USB) |
| `*` / `F` | Повышение/снижение уровня спускового крючка в шагах `1 dB` — вступает в силу в **MANUAL**; в **AUTO** автотрекер перекрывает его на следующем размахе |
| `M` короткий | Переключить режим запуска AUTO/MANUAL |
| `M` Длинный | Сброс анализатора спектра по умолчанию |
| `UP` / `DOWN` на UV-K5 или `LEFT` / `RIGHT` на UV-K1 | Сдвиньте окно подметания вверх/вниз по частоте **Во время RX**: остановите прием и возобновите подметание в выбранном направлении |
| `Side button 1️⃣` | Исключить текущую частоту из спектрального сканирования |
| `Side button 2️⃣` | Переключать подсветку |
| `PTT` | Переход на ** детальный мониторинг** последней полученной частоты |
| `EXIT` | Сохранить постоянные настройки спектра, а затем вернуться к предыдущему экрану / функции |

> [!TIP]
> Развертка чередует направление на каждом полном цикле, чтобы уменьшить направленное смещение. Индикатор `<` / `>` рядом с `A:xxxx` позволяет сразу увидеть, какая половина зачистки в настоящее время активна.

> [!NOTE]
> В MANUAL режиме кривая спектра рисуется без косметического сглаживания. Это делает узкие пики более близкими к необработанному RSSI, используемому детектором гашения.

## Детальный монитор
![LNA](https://github.com/user-attachments/assets/635b7049-4f80-42ba-99e8-ea5295708fab)

### Функция кнопки
* `M` - прокрутка по параметрам, отображаемым в нижней части экрана, которую можно настроить с помощью кнопок `UP` и `DOWN`
   * LNA - усилитель короткого низкого шума
   * LNA - усилитель низкого шума
   * PGA - программируемый усилитель
* `Side button 1️⃣` - Переключить **режим монитора** (принуждает к вскрытию, чтобы вы могли слышать настроенную частоту непрерывно)
* `EXIT` - выходы на предыдущий экран анализатора спектра

> [!NOTE]
> `LNAs` / `LNA` / `PGA` - это ** живые диагностические значения **, а не сохраненные настройки. Они управляются AGC приемника и не сохраняются на выходе. Их доступные шаги и их значение различаются между **BK4819** (V1/V2) и **BK4829** (V3), поэтому они не могут быть сопоставлены по стоимости на разных платформах.
