# FoxHunt и Beacon

Эта страница совместимости сохраняет ссылки, созданные для версий прошивки, где `FOX HUNT / BEACON` был одним комбинированным действием.

Начиная с `v6.0.0`, это два независимых приложения и два независимых программируемых действия:

* [FoxHunt](./Fox-Hunt) является инструментом поиска направления только для приема.
* [Beacon](./Beacon) — автоматический передатчик Морзе.

Комбинированное название сохраняется только при описании исторической реализации `v5.8.0` и `v5.9.0`. Текущие инструкции, элементы управления, информация о доступности и безопасности хранятся на двух отдельных страницах выше.
