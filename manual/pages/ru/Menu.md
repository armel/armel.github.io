# Операция меню

Доступ к меню можно получить с помощью кнопки `M`  (короткое нажатие) .

> [!NOTE]
> Навигация использует `UP` / `DOWN` на UV-K5 или `LEFT` / `RIGHT` на UV-K1. Активная компоновка следует за опцией скрытого меню `SetNav`.

Представленный в Fusion `v5.9.0`, браузер категории используется во всех официальных версиях `v6.0.0` и `v6.1.0`. Выберите категорию с `UP` / `DOWN`, затем нажмите `M`, чтобы открыть список элементов. Выбранный элемент отображается на левой стороне экрана, а его текущее значение отображается справа.

Чтобы найти пункт меню, просмотрите его категорию или выберите `All`, чтобы использовать исходное плоское меню. Вы также можете ввести ** глобальный номер меню ** с экрана категории; например, введите `52` для доступа к `SysInf`. Прямой ввод номера переключается на `All`. Fusion `v5.9.0` использует `01` для `77`; Multiboot-совместимый `v6.0.0` добавляет `SetCfg` и расширяет полный список до `78`.

Как только желаемый пункт меню выделен, нажатие кнопки `M` вводит этот пункт меню.

После выбора пункта меню нажатие кнопок со стрелками `UP` и `DOWN` настраивает настройку для этого элемента. Чтобы подтвердить выбор, нажмите кнопку `M`. Чтобы отменить выбор, нажмите `EXIT`.

Из списка элементов краткое нажатие `EXIT` для возврата в браузер категории. Короткое нажатие `EXIT` снова покидает меню и возвращается на радиоэкран.

## Категоризированный браузер меню

Экран категории Fusion показывает предыдущую, текущую и следующую категории слева. Правая сторона показывает, сколько предметов содержит выделенная категория.

| Категория | Fusion предметы | Содержание |
| --- | ---: | --- |
| `Channels` | 21 в v6 | шаг частоты, мощность, тона, смещение, полоса пропускания, канал и настройки памяти плюс `SetCfg` |
| `Scan` | 6.6 | Список сканирования, приоритетные каналы, режим резюме и двигатель сканирования |
| `Keys` | 1010 | программируемые ярлыки, блокировка клавиатуры, режим PTT и канал вызова |
| `Power` | 4.4 | Защитник / дисплей аккумулятора, тайм-аут бездействия и экранный заставщик |
| `Display` | 11. | дисплей канала, экран запуска, подсветка и настройки пользовательского интерфейса |
| `Timers` | 4.4 | TX тайм-аут, EOT и RX/TX таймеры |
| `Audio` | 5 | микрофон, звуковой сигнал клавиатуры, громкость и аудиопрофили RX |
| `Radio` | 6.6 | Squelch, STE, roger beep, режимы VOX и RX |
| `DTMF` | 5 | коды up/down, боковой тон, предварительная загрузка и декодер live |
| `Service` | 6.6 | скрытые меню запуска; видны только после жеста загрузки скрытого меню |
| `All` | 72 обычно в v6, 78 с обслуживанием | Оригинальный порядок плоского меню и глобальная нумерация |

Счетчик элементов внутри фильтрованной категории является локальным для этой категории. Используйте `All` или введите номер с экрана категории, когда вам нужны глобальные номера, перечисленные ниже.

Прошивка запоминает последнюю выбранную категорию и последний выделенный элемент в каждой категории для текущей сессии. Эти навигационные позиции не сохраняются при перезапуске.

## Быстрые советы

* В `All` первые 13 элементов являются основными живыми настройками VFO/канала.
* `ScList`, `ScPri`, `PriCh1`, `PriCh2` и `ScnRev` являются ключевыми элементами, связанными со сканированием.
* `F1Shrt`, `F1Long`, `F2Shrt`, `F2Long` и `M Long` контролируют настраиваемые ярлыки
* Скрытое меню доступно только при запуске с `PTT` + `SIDE BUTTON 1️⃣`

## Главное меню

Номер перед описанием каждого пункта меню - это номер ** menu, который можно использовать для быстрого выбора.
1. `Step` - шаг частоты (в кГц), кнопки `UP` и `DOWN` изменяют частоту по этому значению, также можно задать только частоту, которая кратна половине этого значения.
1. `Power` - мощность радиоизлучения (LOW 1 / LOW 2 / LOW 3 / LOW 4 / LOW 5 / MID / HIGH / USER). Обратите внимание, что питание пользователя можно настроить через меню `SetPower`.
1. `RxDCS` — приемник Digital-Coded Squelch. Если вы включите это, Squelch разблокируется только в том случае, если этот код будет получен. Вы можете начать сканирование DCS/CTCSS, находясь в этом меню, нажав кнопку `* SCAN`.
1. `RxCTCS` - приемник Continuous Tone-Coded Squelch System. Squelch разблокируется только в том случае, если этот код будет получен. Вы можете начать сканирование DCS/CTCSS, находясь в этом меню, нажав кнопку `* SCAN`.
1. `TxDCS` - передатчик Digital-Coded Squelch, радио будет отправлять данный код при передаче
1. `TxCTCS` - передатчик Continuous Tone-Coded Squelch System, радио будет передавать данный код во время передачи

   В подменю `RxDCS`, `TxDCS`, `RxCTCS` и `TxCTCS` верхний правый значок показывает выбранную запись и ее омологированный индекс:

   * Для CTCSS: `NN/HH`, где `NN` - это позиция в полном списке 50 тонов, а `HH` - омологированный номер тона. `--` означает, что выбранный тон является одним из дополнительных, не гомологированных тонов.
   * Для DCS: `NNN/HH`, где `NNN` находится в полном списке DCS, а `HH` - омологированный номер DCS. `--` означает, что выбранная запись DCS не включена в омологированный список PMR446.
   * `OFF` отображается как `00/00` для CTCSS и `000/00` для DCS.
   * Значения DCS, оканчивающиеся на `N`, являются нормальными кодами; значения, оканчивающиеся на `I`, являются перевернутыми кодами. Перевернутые записи DCS показаны в полном списке, но они не получают омологированный индекс и поэтому показывают `--`.

1. `TxODir` - направление смещения частоты передатчика
1. `TxOffs` - значение смещения частоты передатчика
1. `W/N` - полоса пропускания, используемая приемопередатчиком
   * WIDE - `25 kHz`
   * NARROW - `12.5 kHz`
1. `BusyCL` - блокировка канала, блокирует передачу радиосигнала при приеме сигнала
1. `Compnd` - компандер (компрессор/расширитель), позволяет передавать сигналы с большим динамическим диапазоном по объектам, имеющим меньший динамический диапазон, улучшает качество звука, оба радиоприемника должны использовать эту опцию
1. `Mode` - режим демодуляции, по умолчанию FM, AM/USB можно использовать только для прослушивания
1. `TXLock` - включить или отключить режим передачи канала (если он не охвачен планом `F Lock`)
1. `ChList` - выберите список сканирования канала памяти
1. `ChSave` - сохранение настройки тока в канале памяти
1. `ChDele` - удалить канал памяти
1. `ChName` - изменение названия канала памяти
   * Используйте кнопки `UP` и `DOWN` для выбора канала для редактирования
   * Нажмите кнопку `M` снова, чтобы ввести режим имени редактирования
   * Используйте клавиши счисления в режиме много касаний для редактирования текущего символа, как на старых мобильных телефонах.
     * снова нажать на один и тот же ключ, чтобы прокрутить по нему буквы и номер (`2` = `a`, `b`, `c`, `2` и т.д.)
     * клавиша с длинным нажатием для ввода соответствующего номера непосредственно
     * `F` с коротким нажатием для переключения между строчным и верхним регистром (`abc` / `ABC`)
     * Дальний пресс `F` для входа в `#`
     * короткое нажатие `* SCAN` для ввода `-` или длинное нажатие для ввода `*`
     * короткое нажатие `0` для входа в пространство, затем нажмите его снова для входа в `0`
   * Вы все еще можете использовать кнопки `UP` и `DOWN`, чтобы вручную просматривать доступные символы.
   * Нажмите кнопку `M`, чтобы перейти в следующую позицию персонажа.
   * Повторите два шага, пока не дойдете до конца.
   * Когда всплывет «Sure?», нажмите кнопку `M`, чтобы сэкономить, или отмените выход.
   * Короткое нажатие `EXIT` для перемещения одного персонажа; из первой позиции персонажа он выходит из редактирования имени
   * длительное нажатие `EXIT` отменяет редактирование и возвращает в главное меню.
1. `ScList` - выбирает список сканирования, используемый для сканирования канала: `01` до `24`, `ALL` и, начиная с `v6.1.0`, `MIX`.
   * `MIX` сочетает в себе сохраненный выбор пронумерованных списков без изменения списка, присвоенного каждому каналу.
   * Выберите `MIX` и нажмите `M`, чтобы открыть редактор.
   * Используйте клавиши навигации или введите `01` в `24`, чтобы выбрать список, а затем нажмите `M`, чтобы переключить его.
   * Нажмите `EXIT`, чтобы сэкономить. По крайней мере один список должен быть выбран.
   * См. [список сканирования MIX](./Scanning#mix-scan-list-v610) для полного поведения.
1. `ScPri` - включает/отключает поддержку приоритетных каналов во время сканирования.
1. `PriCh1` устанавливает приоритет канала 1️ -
1. `PriCh2` устанавливает приоритет канала 2️ -
1. `ScnRev` - режим сканирования резюме
   * После того, как сигнал исчезает, пауза на [250 миллисекунд до 20 секунд], прежде чем возобновить сканирование.
   * Остановитесь - после получения сигнала прекратите сканирование
   * TIMEOUT - возобновление сканирования после [5 секунд до 2 минут] паузы
1. `F1Shrt` - функция короткого прессования `SIDE BUTTON 1️⃣`
1. `F1Long` - функция длинного пресса `SIDE BUTTON 1️⃣`
1. `F2Shrt` - функция короткого прессования `SIDE BUTTON 2️⃣`
1. `F2Long` - функция длинного пресса `SIDE BUTTON 2️⃣`
1. `M Long` - кнопка `M` с функцией длинного нажатия
1. `KeyLck` - опция автоматической блокировки клавиатуры (OFF или 15 секунд до 10 минут до автоматической блокировки клавиатуры)
1. `TxTOut` - максимальный предел времени передачи
1. `BatSav` - вариант экономии батареи, скорость между активным временем и временем сна (OFF, 1:1 до 1:5)
1. `BatTxt` - дополнительное значение батареи на строке состояния (`NONE`, `VOLTAGE` или `PERCENT`)
1. `Mic` - чувствительность микрофона
1. `MicBar` - микрофонная панель, которая появляется при передаче 
1. `ChDisp` - стиль отображения канала
1. `POnMsg` - режим запуска дисплея
   * `ALL`: покажите сконфигурированное приветственное сообщение, напряжение и информацию прошивки / версии
   * `SOUND`: сохраняйте нормальное звуковое поведение при запуске без экрана приветствия
   * `MESSAGE`: покажите только настроенное приветственное сообщение
   * `VOLTAGE`: показывает напряжение батареи и предполагаемый процент
   * `LOGO`: покажите пользовательский логотип загрузки 128x64, загруженный [UV Studio](./UV-Studio#boot-logo)
   * `NONE`: пропустите дисплей стартапа
1. `BLTime` - продолжительность подсветки
1. `BLMin` - минимальная яркость подсветки, когда подсветка экрана выключается, она будет тускнеть до этого значения
1. `BLMax` - максимальная яркость подсветки, когда подсветка экрана включается, она станет яркой до этого значения
1. `BLTxRx` - активация подсветки на TX или RX
1. `Beep` - клавишный пресс-звук
1. `Roger` - гудение в конце передачи
1. `STE` - выдавливание хвостового элиминатора, устраняет шум в конце передачи
1. `RP STE` - ретранслятор сдавливания хвостового элиминатора
1. `1 Call` - одноключевой канал вызова; позволяет быстро переключиться на этот канал с помощью кнопки `9 Call`
1. `UPCode` - код DTMF, который отправляется в начале передачи
1. `DWCode` - код DTMF, который отправляется в конце передачи
1. `PTT ID` - наборы, если `UPCode` и/или `DWCode` должны передаваться
1. `D ST` - коммутатор боковых тонов DTMF; позволяет слышать передаваемые тона через радиодинамик
1. `D Prel` - время предварительной загрузки DTMF
1. `D Live` - отображает коды DTMF, принятые по радио в середине экрана
1. `VOX` - уровень чувствительности TX, активированный голосом
1. `SysInf` - системная информация. В текущих F4HWN сборках этот элемент разбит на страницы: введите его с `M`, затем используйте `UP` / `DOWN` для перемещения между страницами.
   * идентификатор: автор прошивки, версия и издание
   * `BUILD`: дата сборки, время сборки и идентификатор фиксации
   * `BATTERY`: измеренное напряжение батареи, предполагаемый процент батареи и выбранный тип / профиль батареи
   * `MEMORY`: использование FLASH и SRAM, когда страница памяти включена в сборку
   * `CODE` / `WIKI`: QR-коды для ссылок проекта, когда страницы QR-кода включены в сборку
1. `RxMode` - устанавливает, как используется верхняя и нижняя частота
   * МАИН ТОЛЬКО - всегда передает и слушает на основной частоте (`MO`)
   * DUAL RX RESPOND - слушает обе частоты, если сигнал принимается на вторичной частоте, он блокируется на нее в течение нескольких секунд, чтобы вы могли ответить на вызов (`DWR`)
   * CROSS BAND - всегда передает на первичной и слушает на вторичной частоте (`XB`)
   * MAIN TX DUAL RX - всегда передает на праймериз, слушает оба (`DW`)
1. `Sql` - уровень чувствительности сдавливания
1. `SetPwr` - установка USER Power
   * LOW 1 (~20 мВт)
   * LOW 2 (~125 мВт)
   * LOW 3 (~ 250 мВт)
   * LOW 4 (~500 мВт, верхний предел по полосе PMR)
   * 5 (~1 Вт)
   * MID (~2 W)
   * Высокая (~5 Вт)
1. `SetPTT` - устанавливает использование PTT
   * Классика
   * ОНЕПУШ
1. `SetTOT`: установлен TOT-оповещение
   * вылет
   * Звучит
   * Визуальный
   * Все ( VISUAL + SOUND )
1. `SetEOT` - устанавливает оповещение EOT (полезно для пауз между 2 передачами)
   * вылет
   * Звучит
   * Визуальный
   * Все ( VISUAL + SOUND )
1. `SetCtr` устанавливает LCD контраст
1. `SetInv` - комплекты LCD инвертированные (лучше всего для ночного видения)
1. `SetLck` - выбирает то, что отключено, пока блокировка клавиатуры активна
   * `KEYS`: блокировка передней клавиатуры; программируемые ярлыки и `PTT` остаются доступными
   * `KEYS + ACTIONS`: также блокируйте программируемые действия, назначенные двум боковым кнопкам и `M Long`; `PTT` остается доступным
   * `KEYS + PTT`: также блокировка `PTT` для предотвращения случайной передачи; программируемые ярлыки остаются доступными
   * `KEYS + ACTIONS + PTT`: блокировка передней клавиатуры, программируемые ярлыки и `PTT`

   В каждом режиме длительное нажатие `F #` для разблокировки радио. См. [Функции кнопок](./Button-functions#keypad-lock-and-setlck) для деталей.
1. `SetMet` - комплекты S-Meter дизайн
   * Классика
   * TINY (например, Yaesu FT4 или FT-65)
1. `SetGUI` - наборы дизайна GUI
   * CLASSIC (больше шрифта, меньше информации)
   * TINY (меньше шрифт, больше информации)
1. `SetRxA` - устанавливает аудиопрофиль RX для текущей модуляции

   Профили `FM`:

   - `FLAT`: самый низкий выходной коэффициент (BK4829-безопасный). Самый нейтральный, лучший для спокойной обстановки.
   - `CLEAN`: сбалансированный профиль по умолчанию. Удобный звук с умеренным усилением.
   - `MID`: более высокая прибыль, чем чистая без агрессивности BOOST.
   - `BOOST`: Голосовой профиль для слабых сигналов / шумных сред. Более высокий выигрыш, более «настоящий» звук.
   - `MAX`: Максимальный выходной коэффициент усиления (может искажаться при сильных сигналах или небольших динамиках). Лучше всего подходит для внешнего динамика.

   Профили `AM`:

   - `SHARP`: Узкий IF фильтр с низким коэффициентом усиления. Более избирательный, с лучшим отторжением соседних каналов. Это может звучать жестче или немного искажено на сильных сигналах, но это остается ясным.
   - `STOCK`: Предназначен для того, чтобы оставаться как можно ближе к поведению прошивки.
   - `OPEN`: более широкий фильтр IF с более высоким коэффициентом усиления. Более открытые и приятные на слабых сигналах, но некоторые приемы могут звучать немного приглушенно, особенно ATC.
1. `SetTmr` - устанавливает, отображаются ли таймеры RX и TX
1. `SetOff` - устанавливает задержку перед тем, как приемопередатчик погрузится в глубокий сон (OFF или от 1 минуты до 2 часов)
1. `SetNFM` - устанавливает Narrow FM на Narrow или Narrower
1. `SetVol` - устанавливает увеличение громкости звука для точной настройки вывода динамика
1. `SetKey` - устанавливает ключ для активации режима RescueOps при запуске приемопередатчика
1. `SetScn` - устанавливает [режим сканирования двигателя](./Scanning#scan-engine-mode-normal-vs-fast).
   * `NORMAL` использует стандартный путь сканирования.
   * `FAST`: использует новый быстрый путь сканирования. Прошивка предварительно проверяет несколько частот / каналов с RSSI, прежде чем выполнять полную настройку приема, быстрее пропускает тихие партии, уточняет близких кандидатов на тонких шагах и использует небольшой сторожевой пёс, чтобы возобновить, если петля сканирования останавливается.
1. `SetSav` - устанавливает [защитный экран](./Radio-operation#screen-saver-and-backlight-timeout), используемый после тайм-аута подсветки, когда включен в сборку.
   * `OFF`: без скринсейвера
   * `LOGO`: покажите пользовательский логотип загрузки в виде праздного экрана
   * `LOGO+`: покажите пользовательский логотип загрузки с эффектом прокрутки
   * `MATRIX`: покажите анимированный холостый экран в матричном стиле

   `SetSav` активен только тогда, когда `BLTime` использует временную продолжительность подсветки. Он приостанавливается во время RX, TX, PTT, BEAM и активного FM-сканирования.
1. `SetCfg` - выбирает банк конфигурации, используемый запущенной прошивкой в сборках `v6.0.0` с поддержкой Multiboot.
   * `CFG M` - основной банк конфигурации
   * `CFG 1` до `CFG 4`: банки конфигурации, связанные со слотами прошивки 1-4

   Нажмите `M` дважды, чтобы подтвердить другой банк. Радио перезагружается, поэтому банк отображается перед загрузкой любых каналов или настроек. Слот прошивки не меняется. Подтверждение того, что банк уже используется, не является операцией. См. [Multiboot и Multiconfig](./Multiboot-and-Multiconfig#using-setcfg).

## Скрытое меню

Скрытое меню активируется удерживанием `PTT` + `SIDE BUTTON 1️⃣` при включении радиоприемника, затем выпуском всех клавиш.

73. `F Lock` - устанавливает план полосы частот TX.
    * DEFAULT+ (137-174, 400-470) - позволяет использовать TX по умолчанию, плюс опции `Tx 200`, `Tx 350`, `Tx 500`
    * FCC HAM (144-148, 420-450)
    * CA HAM (144-148, 430-450)
    * CE HAM (144-146, 430-440)
    * GB HAM (144-148, 430-440)
    * (137-174, 400-430)
    * (137-174, 400-438)
    * PMR 446
    * GMRS FRS MURS
    * DISABLE ALL - отключает TX на всех частотах
    * UNLOCK ALL - включает TX на всех диапазонах. У него есть дополнительный замок; см. [как включить](./Advanced-features#tx-on-all-bands).
74. `350 En` - позволяет использовать RX на `350 MHz`
75. `BatCal` — калибровка напряжения батареи. Сравните отображаемое напряжение с мультиметром и отрегулируйте его, пока они не совпадут как можно ближе.
76. `BatTyp` - тип батареи / кривая разряда, используемая для расчета процента заряда батареи. Это влияет на `%`, а не на измеряемое напряжение.
77. `SetNav` - конфигурирует тип навигации (UP/DOWN для UV-K5, LEFT/RIGHT для UV-K1)
78. `Reset` - сброс настроек радиоконфигурации
   * VFO - удаляет только настройки канала
   * ALL - сброс всех (настройки каналов и радио)

На категоризированном экране меню эти шесть записей отображаются в категории `Service`. Они также добавлены к `All`, где сборка `v6.0.0` с поддержкой Multiboot проходит через `78/78`. На `v5.9.0`, который не имеет `SetCfg`, скрытые записи сохраняют номера `72` до `77`.
