# 频谱分析仪

## 光谱扫描屏幕

按下 `F`+`5 NOAA` 打开**光谱分析仪**。
当前VFO或存储器频率将是频谱扫描的**_中心频率_**。

![光谱分析仪 1](https://github.com/user-attachments/assets/a445dca8-f7e9-4053-bbc9-9d373b03ed2c)

![光谱分析仪 2](https://github.com/user-attachments/assets/01504dbf-e67b-45d3-9c56-b8ebb6b06e05)

光谱分析仪也可以与 [**ScnRng** 模式](./Scanning#scan-frequency-range-function) 一起使用。

> [!NOTE]
> 导航在 UV-K5 上使用 `UP`/`DOWN`，或在 UV-K1 上使用 `LEFT`/`RIGHT`。活动布局遵循 `SetNav`。

> [!NOTE]
> - `PTT` 打开对上次接收频率的详细监控
> - 使用 `ScnRng` 时，黑名单限制为 15 个频率

> [!IMPORTANT]
> 频谱分析仪在不同的无线电硬件上表现并不完全相同。
> **V1 / V2** 收音机采用的是 **BK4819** 接收器，而
> **V3 (K5v3)** 使用的是 **BK4829**。这些是不同的接收器芯片，它们具有……
> 不同的前端、LNA/PGA增益级、AGC行为和RSSI缩放。
>
> 因此：
> - V1/V2 和 V3 之间的**噪声基底**、绝对**dBm / S 表**读数和 **`LNAs`/`LNA`/`PGA` **值**不能直接比较**——在 V2 上看起来“正确”的电平或增益设置在 V3 上没有理由意味着同样的事情；
> - 频谱分析仪已**大幅改进**以支持这两个平台，因此不要指望 V3 能够完全复制您在旧版 V1/V2 上观察到的效果；
> - 高噪声基底或不稳定的噪声基底主要由接收机前端和本地射频环境引起，而非分析仪本身的问题。当**自动**模式无法稳定本地噪声基底时，请切换到**手动**模式并自行设置触发信号——这正是手动模式的用途。

### 触发模式：自动 vs 手动

短按`M`可在**自动**和**手动**触发模式之间切换。左上角的指示灯显示当前模式：

- ** `A:NORM`** / **`A:WEAK`** / **`A:STRG` ** — 自动模式。静噪触发电平会根据灵敏度曲线跟踪测得的噪声基底：
  - `WEAK` — 高于噪声基底 12 dB（灵敏度最低，假开口较少）
  - `NORM` — +8 dB（默认值）
  - `STRG` — +5 dB（最灵敏）
  
标签上会添加一个方向箭头，以显示当前的扫描方向：
  - `>` — 向左→向右扫描
  - `<` — 向右 → 向左扫描
  
例如：`A:NORM>` 表示自动/正常灵敏度，向右滑动。

- ** `M <rssi>/<trig>`** — 手动模式。您可以使用`*`/`F`自行设置静噪触发级别，并使用`3`/`9`设置垂直刻度 (`dbMax`)。触发级别以可预测的`1 dB` 步长变化。

长按`M` **将光谱分析仪重置为默认设置**。

### 退出时保存设置

当您使用 `EXIT` 退出“光谱扫描”屏幕时，光谱分析仪会将持久设置写入闪存。下次打开分析仪时，这些值将被恢复：

- 小节间频率步长（`1`/`7`）
- 条形/通道数 ( `4` )
- 监测信号时使用的接收器带宽 ( `6` )
- 触发模式，**自动** 或 **手动** (`M` 短)
- 自动灵敏度配置文件，**WEAK** / **NORM** / **STRG**（自动模式下为 `3`/`9`）
- 静噪触发电平 (`*`/`F` ) — 在**手动**模式下恢复；在**自动**模式下，每次打开分析仪时都会根据噪声基底重新计算触发电平。

在 `v5.4.0`版本之后，这种持久化功能得到了扩展：旧版本仅保存扫描步长、条形计数和接收器带宽。在当前版本中，从`ScnRng` 模式启动频谱分析仪不再覆盖已保存的扫描步长或条形计数设置；活动扫描范围仍然定义了扫描跨度。

垂直刻度（`dbMax`、`3`/`9`，手动模式下）**不会**保存：每次打开分析仪时，它都会重置为默认显示窗口。当前扫描频率/窗口、`UP`/`DOWN`滚动步长、调制类型、背光切换、临时黑名单和细节监视器寄存器调整（`LNAs`、`LNA`、`PGA`）也不会被此`EXIT`操作保存。如果您位于**细节监视器**屏幕，`EXIT`会首先返回扫描屏幕；从那里再次按下`EXIT`保存并退出分析仪。

当前版本还改进了频段示波器/频谱工作流程中的`8.33 kHz`频率舍入，因此显示和调谐的频率在航空风格的步长上保持更可预测的对齐。

### 按钮功能

| 按键 | 功能 |
| --- | --- |
| `1`/`7` | 增加/减少小节间的频率步长 |
| `2`/`8`| 增加/减少滚动时使用的频率步长`UP`/`DOWN` |
| `3`/`9`| 手动模式下：调整`dbMax`（垂直刻度）· 自动模式下：循环灵敏度曲线（`WEAK`↔`NORM`↔`STRG`）|
| `4` | 切换图表中的柱状图（通道）数量 |
| `5` | 低频扫描频率输入（单位：MHz，`*` = 小数点） |
| `6` | 切换接收器带宽 |
| `0` | 切换调制类型（FM / AM / USB） |
| `*`/`F`| 以`1 dB` 步长增加/减少静噪触发电平 — 在**手动**模式下生效；在**自动**模式下，自动跟踪器会在下一次扫描时覆盖此设置 |
| `M` 短 | 切换自动/手动触发模式 |
| `M` 长 | 将光谱分析仪重置为默认值 |
| UV-K5 上的 `UP`/`DOWN`，或 UV-K1 上的 `LEFT`/`RIGHT` | 上下移动扫描窗口的频率 · **接收期间**：停止接收并恢复沿所选方向的扫描 |
| `Side button 1️⃣` | 从光谱扫描中排除当前频率 |
| `Side button 2️⃣` | 切换背光 |
| `PTT` | 切换到对上次接收频率的**详细监控** |
| `EXIT` | 保存持久光谱设置，然后返回上一屏幕/功能 |

> [!TIP]
> 扫描方向在每个完整周期内交替变化，以减少方向偏差。`A:xxxx`旁边的`<`/`>` 指示器可让您一目了然地看到当前处于活动状态的扫描方向的哪一半。

> [!NOTE]
> 在手动模式下，频谱曲线的绘制不进行任何平滑处理。这使得窄峰与静噪检测器使用的原始RSSI值更加吻合。

## 详细监视器屏幕
![LNA](https://github.com/user-attachments/assets/635b7049-4f80-42ba-99e8-ea5295708fab)

### 按钮功能
* `M`- 用于滚动浏览屏幕底部显示的参数，这些参数可通过`UP`和`DOWN` 按钮进行调整。
   * LNA - 短低噪声放大器
   * LNA - 低噪声放大器
   * PGA - 可编程增益放大器
* `Side button 1️⃣` - 切换**监听模式**（强制打开静噪功能，以便您可以持续听到调谐频率）
* `EXIT` - 返回光谱分析仪的上一屏幕

> [!NOTE]
> `LNAs`/`LNA`/`PGA` 是**实时诊断值**，并非已保存的设置。它们由接收机的自动增益控制 (AGC) 驱动，退出后不会保留。**BK4819** (V1/V2) 和 **BK4829** (V3) 的可用步长及其含义有所不同，因此无法在不同平台上直接比较它们的值。
