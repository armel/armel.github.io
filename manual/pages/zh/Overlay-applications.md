# 叠加应用程序

本页介绍了目前可用于 `Labs` 版本的 11 个应用程序：它们的功能以及如何控制它们。有关安装、兼容性和开发者信息，请参阅 [Overlay apps](./Overlay-apps) 。

> [!NOTE]
> 导航键取决于收音机和`SetNav`设置：UV-K5为`UP`/`DOWN`，UV-K1为`LEFT`/`RIGHT`。在下表中，`UP/LEFT`和`DOWN/RIGHT`指的是这些等效按键。

## 开始申请

1. 安装兼容的 `.app` 文件，并使用 [UV Studio](./UV-Studio#apps-labs) 。
1. 在普通收音机屏幕上，按`F`，然后按`7 VOX`。
1. 选择已安装的应用程序，其值为 `UP/LEFT`或`DOWN/RIGHT` 。
1. 按 `M` 启动它。

在大多数应用程序中，按下`EXIT`会关闭应用程序并返回启动器或普通收音机屏幕。某些收音机应用程序也可以通过常规操作选择器直接分配给可编程按键。

## 应用概要

| 应用 | 目的 |
| --- | --- |
| `Broadcast FM` | 功能齐全的广播调频接收机，带VFO、存储功能和电台扫描功能 |
| `FoxHunt` | 带历史记录、衰减和语音提示的信号强度和方向定位辅助设备 |
| `Beacon` | 使用选定的发射 VFO 重复 ARDF 式莫尔斯电码信标 |
| `Beam` | 通过无线方式在兼容的无线电设备之间传输一个信道配置 |
| `Breakout` | 打砖块游戏 |
| `Tetris` | 带有计分、关卡和保存最高分的下落方块游戏 |
| `Cube3D` | 动画 3D 形状查看器 |
| `Plasma` | 动画演示场景风格图案 |
| `Snake` | 经典的网格贪吃蛇游戏，可保存最高分 |
| `Rapid Roll` | 一款平台游戏，玩家控制的小球必须不断向下滚动，避开各种障碍物 |
| `Space Impact` | 横版卷轴太空射击游戏，包含自动射击、导弹和Boss战 |

## 广播调频

`Broadcast FM` 是一款完整的 BK1080 广播接收机。它提供频率和存储模式、四个广播频段、手动搜索、自动电台发现，以及与内置 FM 收音机共享的 48 个 FM 存储。

此应用程序运行时，BK4819 的正常接收和双频监听功能将被暂停。应用程序退出时，对 FM 存储器的更改将安全提交。

| 按键 | 操作 |
| --- | --- |
| `0`–`9` | 在 VFO 模式下输入频率，或在 MR/保存模式下输入两位数的存储编号 |
| `UP/LEFT`或`DOWN/RIGHT` | 在 VFO 模式下调谐一个步长；在 MR 模式下选择上一个/下一个已存储的电台；选择保存槽；在扫描时更改搜索方向 |
| `*` | 开始手动搜索；停止正在进行的扫描 |
| 按`F`，然后按`*`或按住`*` | 开始自动扫描并重建FM记忆列表 |
| `M`处于 VFO 模式 | 打开`SAVE?`；再次按下`M` 以保存到选定的插槽 |
| `M`在 MR 模式下 | 打开`DEL?`；再次按下 `M` 删除选定的内存 |
| 按`F`，然后按`1`或按住`1` | 选择下一个广播频段 |
| 按`F`，然后按`3`或按住`3` | 在VFO和MR模式之间切换 |
| 按`F`，然后按`0`或按住`0` | 退出应用程序 |
| `EXIT` | 删除最后输入的数字、取消保存/删除提示或退出 |

> [!WARNING]
> 自动扫描会在存储找到的电台之前，清除并重建 FM 存储列表。

## 猎狐

`FoxHunt` 可帮助您使用选定的接收 VFO 定位发射机。它以 dBm 为单位显示校正后的信号强度，并提供 IARU 标准的信号强度表、峰值和最小值、趋势信息以及条形图或信号历史记录。可选的衰减功能可扩展在强发射机附近的有效范围。

| 按键 | 操作 |
| --- | --- |
| `1` | 在柱状图和信号历史记录之间切换 |
| `2` | 选择下一个音频模式：关闭、强音提示音或连续电台音频 |
| `3` | 增强衰减 |
| `F`，然后 `2` | 选择上一个音频模式 |
| `F`，然后 `3` | 降低衰减 |
| `UP/LEFT`或`DOWN/RIGHT` | 直接增加/减少衰减 |
| `M` | 重置峰值、最小值和趋势参考值 |
| 按住 `F` | 锁定或解锁应用程序键盘 |
| `EXIT` | 键盘解锁时退出 |

图形、音频模式和衰减设置将被保存，以便下次启动。即使应用程序键盘被锁定，两个导航键仍然可用。

## 灯塔

`Beacon`在选定的发射 VFO 上重复发送 ARDF 风格的莫尔斯电码标识符。它在可配置的发射窗口和空闲期之间交替。可用的标识符有`MOE`、`MOI`、`MOS`、`MOH`、`MO5`、`MO`和`CALL`；`CALL`发送配置的呼号，然后发送`MOE`。

| 按键 | 操作 |
| --- | --- |
| `1` | 以 5 秒为步长增加传输持续时间（`5`–`60` 秒） |
| `2` | 以 5 秒为步长增加空闲持续时间（`5`–`240` 秒） |
| `3` | 选择下一个标识符 |
| `4`| 切换`TONE`/`CARR` 键控 |
| `F`，然后 `1`/`2`/`3`/`4` | 反向更改相应的设置 |
| `M` 传输期间 | 停止当前传输窗口并开始空闲期 |
| `M` 空闲时 | 重新启动完整的空闲倒计时 |
| 按住 `F` | 锁定或解锁所有应用程序控件 |
| `EXIT` | 安全停车并退出，同时保持控制解锁 |

首次传输立即开始。传输持续时间、空闲时间、标识符和密钥模式将被保存，以便下次启动。如果驻留固件拒绝传输，应用程序将显示`TX OFF`，并且不会进行传输。

> [!WARNING]
> 信标会自动发射。发射前，请检查所选的VFO、频率、功率、天线、呼号、占空比以及当地法规。

## 光束

`Beam` 用于在兼容的无线电设备之间传输选定的 VFO 或存储信道配置。发送方无线电设备通过无线方式发送信道数据；接收方无线电设备将有效数据包存储在第一个空闲存储器中。

| 按键 | 操作 |
| --- | --- |
| `UP/LEFT`或`DOWN/RIGHT`| 在发送 (`BEAM TX`) 和接收 (`BEAM RX` ) 模式之间切换；也可停止正在进行的接收操作 |
| `M` 处于 TX 模式 | 发送选定的通道配置 |
| `M` 处于接收模式 | 开始等待光束数据包 |
| `EXIT` | 停止接收或退出应用程序 |

显示屏会根据情况报告`SENT`、`RECEIVED`、`MEM FULL`或`ERROR`。每次启动仅占用一个接收到的通道；接收下一个通道前，请退出并重新打开Beam。

## 突破

`Breakout` 是一款小巧的打砖块游戏，包含 18 个砖块、5 个初始球、计分和关卡追踪功能。清除墙壁即可进入下一关并获得一个额外的球。

| 按键 | 操作 |
| --- | --- |
| `4`或`UP/LEFT` | 将拨片向左移动 |
| `0`或`DOWN/RIGHT` | 将拨片向右移动 |
| `M`| 暂停或恢复；在`GAME OVER` 之后，开始准备好的新游戏 |
| `EXIT` | 退出应用程序 |

退出应用程序后，游戏进度将不会保留。

## 俄罗斯方块

`Tetris` 使用 16 × 16 的可视区域、随机排列的七块方块袋、幽灵方块、下一块方块预览、分数、线条和关卡。每次游戏都会保存最高分。

| 按键 | 操作 |
| --- | --- |
| `4`或`UP/LEFT` | 向左移动 |
| `6`或`DOWN/RIGHT` | 向右移动 |
| `M`或`2` | 旋转部件 |
| `8` | 柔和的滴落 |
| `*`或`0` | 硬摔 |
| `F` | 暂停或恢复 |
| 游戏结束后按 `M`、`*` 或 `0` | 开始新游戏 |
| `EXIT` | 退出应用程序 |

在握住钥匙的同时，动作和轻柔的落下动作会重复进行。

## Cube3D

`Cube3D` 可渲染旋转的实体或线框形状。提供八种形状：立方体、八面体、四面体、菱形、二十面体、立方八面体、六棱柱和五角宝石。

| 按键 | 操作 |
| --- | --- |
| `UP/LEFT`或`DOWN/RIGHT`| 增加/减少旋转速度 (`1`–`16` ) |
| `1`–`8` | 直接选择形状 |
| `*` | 选择下一个形状 |
| `F` | 切换线框/实体渲染 |
| `M` | 暂停或恢复 |
| `EXIT` | 退出应用程序 |

## 等离子体

`Plasma` 显示动画全屏演示场景风格的图案，可以是条带状或点状渲染。

| 按键 | 操作 |
| --- | --- |
| `UP/LEFT`或`DOWN/RIGHT`| 增加/减少动画速度 (`1`–`8` ) |
| `1`–`5` | 选择图案并禁用自动循环 |
| `*` | 切换条纹/点状渲染 |
| `F` | 启用或禁用自动图案循环 |
| `M` | 暂停或恢复 |
| `EXIT` | 退出应用程序 |

## 蛇

`Snake`是一款经典的诺基亚风格游戏，在`31 × 13`网格上进行。吃掉食物让蛇长大，并获得`10` 分数。碰到边界或蛇的身体就会结束游戏。每次游戏都会保存最高分。

| 按键 | 操作 |
| --- | --- |
| `2`或`3` | 向上移动 |
| `4`或`5` | 向左移动 |
| `6`或`0` | 向右移动 |
| `8`或`9` | 向下移动 |
| `F` | 暂停或恢复 |
| 游戏结束后按 `M`、`*` 或 `0` | 开始新游戏 |
| `EXIT` | 退出应用程序 |

按住方向键可重复此操作。应用程序不允许立即返回蛇的身体。如果在游戏过程中屏幕保护程序启动，贪吃蛇游戏将暂停，并在唤醒后继续运行。

## 快速滚动

`Rapid Roll`是一款平台游戏，游戏中的平台会不断上升，最终到达布满尖刺的天花板。玩家需要横向移动小球，从一个安全的平台落到下一个平台上。尖刺平台、天花板和屏幕底部都会消耗一条生命；从第 3 关开始，平台会逐渐崩塌。爱心可以奖励`50` 分数并恢复一条生命，最多可恢复五条生命。

| 按键 | 操作 |
| --- | --- |
| `4`或`UP/LEFT` | 向左滚动 |
| `6`或`DOWN/RIGHT` | 向右滚动 |
| `F` | 暂停或恢复 |
| `M` 游戏结束后 | 开始新游戏 |
| `EXIT` | 退出应用程序 |

游戏开始时玩家有三条命，随着关卡提升，游戏速度会加快。安全平台在高关卡中会变得更窄。退出应用程序后，游戏进度将不会保留。如果在游戏过程中屏幕保护程序启动，快速滚动模式会暂停，并在唤醒后继续运行。

## 太空冲击

《`Space Impact`》是一款横版射击游戏。飞船会自动开火，玩家可以自由操控飞船进行垂直移动。敌人会一波接一波地出现，采用多种移动和攻击模式，每关最后都会有一个带有可见血条的 Boss 战。

| 按键 | 操作 |
| --- | --- |
| `2`或`UP/LEFT` | 将飞船向上移动 |
| `8`或`DOWN/RIGHT` | 将飞船向下移动 |
| `5`或`M` | 发射一枚穿甲导弹 |
| `F` | 暂停或恢复 |
| `M` 游戏结束后 | 开始新游戏 |
| `EXIT` | 退出应用程序 |

游戏开始时玩家拥有三条命和三枚导弹。主炮会自动开火。每击杀16个敌人即可获得一枚导弹，最多可获得九枚。击败首领后，如果生命值和导弹数量低于上限，则会获得额外的生命值和导弹。退出应用程序后，游戏进度将不会保留。如果在游戏过程中屏幕保护程序启动，《太空冲击》将暂停游戏，并在唤醒后继续运行。
